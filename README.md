## Коротко о продукте

DCT это внешняя обработка 1С, работающая внутри вашего контура. Конфигурацию менять не требуется, зависимости от БСП нет, данные не покидают инфраструктуру компании.

- Статистическая эффективность сжатия 45–75%, что соответствует сокращению размера базы в 2–3 раза
- База на 500 ГБ обрабатывается за 4–8 часов
- Многопоточная свёртка до 8 потоков с балансировщиком нагрузки
- Встроенные отчёты: анализ сжимаемости (прогноз результата), анализ размеров таблиц, анализ ссылочной целостности, сверка остатков «до/после»
- Автоматический запуск по расписанию и конвейер для нескольких баз
- 300+ успешных внедрений
- Включён в реестр российского ПО, защищён патентом Роспатента, победитель Infostart Awards 2024
