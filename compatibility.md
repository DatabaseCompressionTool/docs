## Главное о совместимости

DCT работает с любой конфигурацией «1С:Предприятия 8»: типовой, доработанной или самописной, с управляемыми и обычными формами. Наличие БСП не требуется. Сервер 1С:Предприятия должен работать под Windows, а вот СУБД может стоять и на Linux: связка «сервер 1С на Windows + PostgreSQL на Linux» поддерживается полностью.

## Поддерживается

| Область | Описание |
|---|---|
| Режимы запуска | Управляемые и обычные формы. Обычные формы доступны начиная с редакции PROFESSIONAL |
| Конфигурации | Любые нетиповые конфигурации, любые нетиповые объекты в типовых конфигурациях, добавленные как непосредственно, так и расширениями |
| Многопоточность | Свёртка в несколько потоков в файловых и серверных базах, до 8 потоков с балансировщиком |
| СУБД | MS SQL Server (2008–2025), PostgreSQL (9–18, включая сборки для 1С), файловые базы |
| Операционные системы | Сервер 1С под Windows. СУБД под Windows или Linux: размещение MS SQL Server и PostgreSQL на Linux поддерживается полностью |
| Виды объектов | Документы, справочники, регистры накопления, регистры сведений, регистры бухгалтерии |

## Не поддерживается

| Область | Описание |
|---|---|
| Сервер приложений на Linux | Ограничение касается только сервера 1С:Предприятия. Если сервер 1С работает на Windows, а СУБД на Linux, продукт работает штатно |
| Облачный сервис 1С:Fresh | Базы данных в сервисе не обрабатываются |
| Разделение данных | Базы с принудительно включённым механизмом разделения данных |
| СУБД IBM DB2 и Oracle Database | Не поддерживаются |
| Регистры расчёта | Зарплатные регистры расчёта продукт намеренно не изменяет: записи прошлых периодов участвуют в текущих расчётах, поэтому их движения сохраняются полностью. Остальные данные зарплатных конфигураций (регистры сведений, регистры накопления, счета учёта расчётов с персоналом) сворачиваются штатно |

Часть ограничений снимается в новых версиях продукта. Что уже изменилось, видно в [истории версий](CHANGELOG.md).

## Требования к оборудованию

Приоритет ресурсов при свёртке выглядит так: дисковая подсистема, затем частота процессора, затем объём оперативной памяти. Ориентиры: последовательная скорость диска от 1000 МБ/с, около 16 ГБ ОЗУ на базу в 500 ГБ. Отдельно нужно заложить свободное место на дисках, считая его от размера базы **до** свёртки, а не после.

Подробный разбор: [Железо для свёртки базы 1С](https://databasecompressiontool.ru/articles/zhelezo-dlya-svertki-1s)

## Работа в закрытом контуре

Для активации лицензии и периодической проверки нужен доступ к серверу лицензирования через интернет. Полностью автономная работа в изолированном контуре невозможна, но открывать требуется доступ только к одному интернет-ресурсу.
